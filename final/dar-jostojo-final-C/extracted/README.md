# Dar Jostojo source-3 extraction

This folder is intentionally separate from `final/dar-jostojo-final-C/`.

- `supplemental-whole-files/`: source-3 files that do not map cleanly to a Final-C lesson.
- `missing-core/`: source-3 material that appears to recover a missing core Final-C lesson.
- `candidate-differences/`: low-overlap paragraphs inside mapped lessons, kept for manual editorial inspection only.

Nothing here is automatically promoted into Final-C.
