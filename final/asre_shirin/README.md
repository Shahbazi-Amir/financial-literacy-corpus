# عصر شیرین — Final Candidates

این پوشه مرجع سوم پروژه است.

- `متن ها/` = متن‌های مرتب‌شده و صوت‌بازبینی‌شده کاربر؛ مرجع مستقل و بدون تغییر.
- `outputs/asre_shirin/review/` = Review/Output قبلی ChatGPT؛ مرجع مستقل و بدون تغییر.
- `final/asre_shirin/md/` = نسخه‌های حاصل از تطبیق دو مرجع.

## وضعیت تأیید

فایل‌های این پوشه تا وقتی قسمت‌به‌قسمت بررسی و تأیید نشوند **Final Candidate** هستند، نه Canonical نهایی.

در کار قبلی، قسمت‌های ۱ تا ۴ عمدتاً محافظه‌کارانه ویرایش شدند؛ قسمت ۱۵ به دلیل نبودن Output مستقل بازسازی شد؛ و قسمت‌های ۵–۱۴ و ۱۶–۲۶ بیش از حد وارد بازساخت/فشرده‌سازی شدند و باید دوباره دو‌به‌دو بررسی شوند.
